# WNC AI MCP — distribution channel

This public repository is the **update channel** for the WNC AI MCP WordPress plugin
(a private MSP tool for WebNetCom). It contains only packaged releases — the plugin's
built-in updater reads the latest Release here and offers it inside WordPress.

- Install/upgrade: download `wnc-ai-mcp.zip` from the latest Release and upload it via
  **Plugins → Add New → Upload**, or use the plugin's **Check for updates** button.
- Source is maintained privately.
